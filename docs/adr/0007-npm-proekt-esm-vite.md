# npm-проект: ES-модули и Vite вместо классических скриптов

> **Status:** принято — решение владельца 2026-10-25 («1 и 2, используй vite (npm run dev); зависимости разрешены; подправь pages»). Частично пересматривает ADR-0005 (способ загрузки модулей) и уточняет инвариант ADR-0004 «открыл `index.html` — играешь».

## Что изменилось

Проект стал настоящим npm-пакетом: `package.json` с `"type": "module"` и скриптами (`dev` / `build` / `preview` / `test`), все модули переведены с IIFE + CommonJS-гардов на ES-модули с дефолтным экспортом, тесты — на `import` (`node:test` работает с ESM без изменений ритуала). Вход для браузера — один `<script type="module" src="./js/app.js">` вместо семи классических тегов; `app.js` импортирует остальных.

## Vite как dev-сервер и сборщик

`npm run dev` — мгновенный dev-сервер с модулем ES-графа; `npm run build` — производственная сборка в `dist/` (Vite 8). `base: './'` даёт относительные пути ассетов — сайт живёт в подпапке `/Hyper-Cube/` на GitHub Pages. Workflow Pages упрощён до канонического: Node 22 → `npm ci` → `npm run build` → публикация `dist/`; ручные `scripts/build.sh` / `build.cmd` удалены — их заменяет сам Vite. Отклонённые альтернативы: остаться на классических скриптах (нет dev-сервера и явного графа зависимостей), Node-бэкенд для игры (противоречит host-авторитарному P2P — ADR-0006).

## Инвариант запуска

Прямое открытие `index.html` через `file://` больше не работает — браузеры блокируют ES-модули с файлового протокола. Локальный запуск — `npm run dev`, прод — Pages. Суть старого инварианта сохранена на уровне «нет фреймворков и ручной сборки»: вся игровая логика остаётся чистыми модулями без зависимостей, Vite — только среда разработки и упаковки. Тесты по-прежнему не требуют ничего, кроме Node: `npm test` = `node --test` (Vite — devDependency, в тестах не участвует).

## PeerJS — npm-зависимость с ленивым импортом

`peerjs` берётся обычной зависимостью, но подключается ленивым динамическим импортом внутри `Net.host`/`Net.join` — Vite выносит его в отдельный чанк (~23 кБ gzip), который грузится только при открытии или подключении к комнате. Node-тесты транспортного модуля (`makeCode`/`normalize`/`isValid`) пакет не затрагивают, CDN-скрипт из `index.html` убран: версия зафиксирована в lockfile вместо «что сегодня отдаёт CDN».

## Инструменты качества

`oxlint` и `oxfmt` — devDependencies с нулевой конфигурацией сверх `singleQuote`: `npm run lint` / `npm run format`. Линтер поймал три категории при внедрении (неиспользуемые биндинги catch, `new Array(n)`, мёртвый параметр `send` в `Session.host`) — все устранены, а не заглушены настройками.
