# Блокировка абсолютного центра в режиме «Классика»

> **Status:** утратил силу — режим «Классика» удалён вместе с механизмом блокировки (ADR-0004).

Изначально (ADR-0001) правила «Классики» (3×3×3×3, «3 в ряд») оставлены чистыми: абсолютный центр (1,1,1,1) лежит на всех 40 направлениях линий, первый игрок выигрывает форсированно, а дисбаланс предполагалось компенсировать только чередованием стартёра. Решение пересмотрено: центр навсегда заблокирован для ходов — клетка отображается как заблокированная, движок и ИИ её игнорируют, а линии через центр считаются «мёртвыми» и исключаются из оценки ИИ. Это устраняет тривиальный форс-вин без нестандартных фаз вроде правила пирога. Отклонённые альтернативы: чистые правила (дисбаланс сохраняется) и правило пирога (усложняет интерфейс дополнительной фазой).
