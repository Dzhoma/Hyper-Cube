# Углубление после архитектурного обзора: модуль Match, state-интерфейс, единый i18n, тесты

> **Status:** принято — все пять кандидатов обзора архитектуры от 2026-10-24 приняты владельцем («принимай все и начинай»).

## Модуль Match

Логика матча — серия раундов, счёт, чередование стартёра, ход ИИ — выделена из app.js в отдельный модуль `js/match.js` с маленьким interface (newMatch / nextRound / restartRound / play / aiMove / isAiTurn + game / score / round). Зависимости (ядро, ИИ, генератор случайности) инъецируются: в браузере их передаёт app.js, в тестах — фейки. Два адаптера за seam (настоящий AI и фейковый в тестах) делают seam настоящим. Отклонённая альтернатива: оставить плоский IIFE app.js — каждая новая фича расширяла бы общий mutable scope.

## State ядра — объявленный interface

Plain-data state GameCore объявлен частью interface ядра: его читают app.js и ai.js, и это честный, тест-ориентированный выбор. Контракты, жившие в комментариях и продублированные у потребителей, стянуты в ядро: формула адресации (`idxOf`), кодировка символов и ничьей (`X` / `O` / `DRAW`), справка о поле (`facts`), параметр стартёра в `create(n, { starter })` — app.js больше не пишет в `game.turn`. Отклонённые альтернативы: прятать state за аксессорами (сузило бы тестовую поверхность) и оставить контракты в комментариях.

## Единый механизм i18n

Все переводы идут через один словарь и один путь перерендера (`setLang`): блоки правил EN/RU в index.html слиты в одну разметку с `data-i18n` / `data-i18n-html`, числа поля (520 / 256 / 4×4×4×4) приходят параметрами из `GameCore.facts`, aria-метки клеток пересчитываются при смене языка — устранён баг со «запечёнными» при постройке поля метками. Отклонённая альтернатива: сохранять второй HTML-блок правил на язык — ручной список инвалидации уже давал баг.

## Seam уровней ИИ

Задержка перед ходом ИИ (UI-ритм) переехала из app.js в ai.js (`delayFor`) — уровень больше не «магический int», расползающийся по трём файлам; смыслы уровней документированы в ai.js, строки меню живут в i18n. Полный «реестр уровней» отклонён: deletion test спорный при трёх уровнях.

## Тестопригодная загрузка

Модули game / ai / match получают CommonJS-экспорт-гард (в браузере `module` не существует) — один способ загрузки для `<script>` и `require`, без этапа сборки. RNG ИИ инъецируется (`choose(state, level, { rng })`), тесты на `node:test` в `tests/` детерминированы. Отклонённые альтернативы: eval-исходников в тестах (хрупкий хак) и добавление сборщика (нарушает принцип «открыл index.html — играешь»).
