# Удаление режима «Классика»

Игра оставлена с единственным полем — «Гиперкуб» (4×4×4×4, «4 в ряд», 520 линий). Режим «Классика» (3×3×3×3, «3 в ряд», 272 линии) удалён из меню, ядра и ИИ. Причины: при идеальной игре «Классика» форсированно выигрывается первым игроком (ADR-0001), а после блокировки центра (ADR-0003) её правила уже не были каноничными; с единственным режимом переключатель поля в меню стал бессмысленным, а из ядра и ИИ полностью ушла механика заблокированных клеток и «мёртвых» линий. Ядро осталось параметризованным по n — возврат меньшего поля при необходимости не требует переделки. Отклонённые альтернативы: оставить оба режима с одним активным пунктом переключателя (мёртвый UI) и ослаблять «Классику» гандикапами (нестандартные правила).
