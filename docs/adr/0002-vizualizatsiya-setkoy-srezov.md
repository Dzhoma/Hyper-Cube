# Визуализация гиперполе сеткой 2D-срезов

Четырёхмерное поле отображается сеткой двумерных срезов: 9 срезов 3×3 («Классика») или 16 срезов 4×4 («Гиперкуб»), каждый срез — доска по двум оставшимся координатам. 3D-сцена (Three.js/WebGL) отклонена: точность попадания клика падает, а четвёртое измерение всё равно пришлось бы раскрывать слайдером или слоями, то есть сложность растёт без выигрыша в читаемости. Неоновая 3D-графика допустима позже только как эффект победы, не как игровая поверхность.
